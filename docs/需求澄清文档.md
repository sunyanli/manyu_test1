# 人员看板系统 - 需求澄清文档

## 一、项目概述

**项目名称**: 人员看板管理系统（Employee Dashboard System）
**项目标识**: manyu_test1
**当前阶段**: 需求澄清 → 设计阶段

### 核心需求
开发一个人员管理看板系统，提供员工基本信息的记录、管理、导入功能，并支持成本预算跟踪。

---

## 二、功能需求分析

### 2.1 核心功能模块

#### 模块1：员工基本信息管理
**功能点**:
- ✅ 员工信息录入（新增）
- ✅ 员工信息查询（查询单条/列表）
- ✅ 员工信息修改（更新）
- ✅ 员工信息删除（删除）

**员工实体核心字段**:
```
- id: 唯一标识
- name: 姓名
- employeeId: 工号（业务主键）
- gender: 性别
- birthDate: 出生日期
- phone: 联系电话
- email: 邮箱
- department: 部门
- position: 职位
- hireDate: 入职日期
- status: 在职状态（在职/离职）
- salary: 薪资
- budget: 成本预算
- remarks: 备注
- createdAt: 创建时间
- updatedAt: 更新时间
```

#### 模块2：数据导入功能
**功能点**:
- ✅ Excel文件导入（.xlsx/.xls）
- ✅ CSV文件导入
- ✅ 导入数据校验
- ✅ 导入结果反馈（成功/失败条数、错误提示）
- ✅ **批量导入初始化文件**：支持一次性导入大量人员初始化数据
- ✅ **智能格式识别**：自动识别文件格式（Excel/CSV），自动识别字段映射
- ✅ **详细失败反馈**：接口返回失败明细（行号、字段、错误原因）

#### 模块3：白名单打标管理
**功能点**:
- ✅ 员工标签设置（白名单标记）
- ✅ 白名单员工查询与筛选
- ✅ 批量打标操作
- ✅ 标签类型管理（核心员工、关键岗位、特殊人才等）
- ✅ 打标记录追踪

#### 模块4：成本预算管理
**功能点**:
- ✅ 设置员工成本预算
- ✅ 预算金额汇总统计
- ✅ 部门预算分布查看
- ✅ 预算与实际薪资对比
- ✅ **层级分类预算展示**：按组织层级（公司→部门→团队→个人）分级展示预算
- ✅ **预算层级下钻**：支持从总预算逐级下钻查看各层级预算明细
- ✅ **预算汇总计算**：自动计算各层级预算总额及占比

#### 模块5：看板展示
**功能点**:
- ✅ 员工列表总览
- ✅ 部门人员分布图表
- ✅ 预算统计看板
- ✅ 关键指标卡片展示

## 三、技术方案设计

### 3.1 架构选型

**架构模式**: 前后端分离架构

**技术栈推荐**:

#### 前端技术栈
- **框架**: Vue 3 + TypeScript
- **UI组件库**: Element Plus
- **状态管理**: Pinia
- **路由**: Vue Router
- **HTTP客户端**: Axios
- **图表库**: ECharts
- **构建工具**: Vite

#### 后端技术栈
- **框架**: Spring Boot 2.7+ / 3.x
- **语言**: Java 17+
- **ORM**: MyBatis-Plus
- **数据库**: MySQL 8.0 / PostgreSQL
- **文档**: Swagger/Knife4j
- **文件处理**: EasyExcel（Excel导入）

#### 数据库设计
- **主数据库**: MySQL（员工信息、预算数据）
- **表设计**: 
  - `t_employee`: 员工基础信息表
  - `t_budget_record`: 预算记录表（可选，若需要历史追踪）

## 四、数据库设计

### 4.1 员工表（t_employee）

| 字段名 | 类型 | 长度 | 必填 | 说明 |
|--------|------|------|------|------|
| id | BIGINT | - | 是 | 主键，自增 |
| employee_no | VARCHAR | 50 | 是 | 工号，唯一索引 |
| name | VARCHAR | 100 | 是 | 姓名 |
| gender | TINYINT | - | 否 | 性别：0-未知，1-男，2-女 |
| birth_date | DATE | - | 否 | 出生日期 |
| phone | VARCHAR | 20 | 否 | 联系电话 |
| email | VARCHAR | 100 | 否 | 邮箱 |
| department | VARCHAR | 100 | 否 | 部门 |
| position | VARCHAR | 100 | 否 | 职位 |
| hire_date | DATE | - | 否 | 入职日期 |
| status | TINYINT | - | 是 | 状态：1-在职，0-离职，默认1 |
| salary | DECIMAL | 10,2 | 否 | 薪资 |
| budget | DECIMAL | 10,2 | 否 | 成本预算 |
| whitelist_tag | VARCHAR | 100 | 否 | 白名单标签（核心员工/关键岗位/特殊人才等） |
| tag_time | DATETIME | - | 否 | 打标时间 |
| remarks | VARCHAR | 500 | 否 | 备注 |
| created_at | DATETIME | - | 是 | 创建时间 |
| updated_at | DATETIME | - | 是 | 更新时间 |

**索引设计**:
- 主键：`PRIMARY KEY (id)`
- 唯一索引：`UNIQUE INDEX uk_employee_no (employee_no)`
- 普通索引：`INDEX idx_department (department)`, `INDEX idx_status (status)`

## 五、API接口规划

### 5.1 员工管理接口

| 接口名称 | 方法 | 路径 | 说明 |
|---------|------|------|------|
| 员工列表 | GET | /api/employees | 分页查询员工列表 |
| 员工详情 | GET | /api/employees/{id} | 查询单个员工详情 |
| 新增员工 | POST | /api/employees | 创建员工记录 |
| 更新员工 | PUT | /api/employees/{id} | 更新员工信息 |
| 删除员工 | DELETE | /api/employees/{id} | 删除单个员工 |
| 批量删除 | DELETE | /api/employees/batch | 批量删除员工 |

### 5.2 导入接口

| 接口名称 | 方法 | 路径 | 说明 |
|---------|------|------|------|
| Excel导入 | POST | /api/import/excel | 上传Excel文件导入（自动识别格式） |
| CSV导入 | POST | /api/import/csv | 上传CSV文件导入 |
| 导入模板下载 | GET | /api/import/template | 下载导入模板 |

**导入响应结构（详细失败反馈）**:
```json
{
  "success": true,
  "data": {
    "totalRows": 100,
    "successCount": 95,
    "failCount": 5,
    "failDetails": [
      {
        "row": 10,
        "field": "phone",
        "value": "123",
        "error": "手机号格式不正确"
      }
    ]
  }
}
```

### 5.3 白名单打标接口

| 接口名称 | 方法 | 路径 | 说明 |
|---------|------|------|------|
| 设置标签 | POST | /api/whitelist/tag | 为员工设置白名单标签 |
| 批量打标 | POST | /api/whitelist/batch-tag | 批量为员工打标 |
| 移除标签 | DELETE | /api/whitelist/tag/{id} | 移除员工标签 |
| 标签列表 | GET | /api/whitelist/tags | 获取标签类型列表 |
| 白名单员工查询 | GET | /api/whitelist/employees | 查询白名单员工列表 |

### 5.4 层级预算接口

| 接口名称 | 方法 | 路径 | 说明 |
|---------|------|------|------|
| 公司预算总览 | GET | /api/budget/company | 获取公司级别预算汇总 |
| 部门预算列表 | GET | /api/budget/departments | 获取各部门预算明细 |
| 部门预算下钻 | GET | /api/budget/departments/{deptId}/teams | 下钻查看部门下团队预算 |
| 团队预算明细 | GET | /api/budget/teams/{teamId}/members | 查看团队员工预算明细 |
| 层级预算树 | GET | /api/budget/tree | 获取完整层级预算树结构 |

### 5.3 统计看板接口

| 接口名称 | 方法 | 路径 | 说明 |
|---------|------|------|------|
| 看板总览 | GET | /api/dashboard/overview | 获取看板关键指标 |
| 部门统计 | GET | /api/dashboard/department-stats | 部门人员分布统计 |
| 预算统计 | GET | /api/dashboard/budget-stats | 预算汇总统计 |

## 七、非功能性需求

### 7.1 性能要求
- 员工列表查询响应时间 < 500ms（1000条数据以内）
- 导入处理速度 > 100条/秒

### 7.2 安全要求
- 接口鉴权机制（JWT Token）
- 敏感字段脱敏（薪资、预算可见性控制）
- SQL注入防护
- XSS防护

### 7.3 兼容性要求
- 前端支持主流浏览器（Chrome、Edge、Firefox）
- 移动端响应式适配（可选）
