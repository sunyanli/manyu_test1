# 排序算法 - 需求澄清与设计文档

## 1. 需求概述

实现一个通用排序算法模块，为 `manyu_test1` 项目提供数组排序能力。

## 2. 需求澄清

| 维度 | 决策 | 依据 |
|------|------|------|
| 编程语言 | JavaScript (ES6+) | 匹配现有项目 `helloworld.js` 的技术栈 |
| 算法选型 | 快速排序 (Quicksort) | 平均 O(n log n)，原地排序，工业标准 |
| 输入类型 | `Array<number>` | 最常见场景，后续可扩展泛型 |
| 排序方向 | 升序（默认） | 行业惯例，通过比较器支持降序 |
| 稳定性 | 非稳定（原地） | 快速排序经典实现，性能优先 |
| 比较器 | 可选自定义 `(a, b) => number` | 支持复杂对象排序 |
| 边界处理 | 空数组 / 单元素直接返回 | 防御性编程 |

## 3. 设计方案

### 3.1 算法：快速排序 (Quicksort)

- **分区策略**：Lomuto 分区，选取最右元素为 pivot
- **递归基线**：子数组长度 ≤ 1 时终止
- **空间复杂度**：O(log n) 递归栈
- **时间复杂度**：平均 O(n log n)，最坏 O(n²)

### 3.2 API 设计

```js
/**
 * 对数组进行升序排序（原地修改）
 * @param {number[]} arr - 待排序数组
 * @param {Function} [compareFn] - 可选比较器 (a, b) => a - b 为升序
 * @returns {number[]} 排序后的数组（同引用）
 */
function quickSort(arr, compareFn = (a, b) => a - b)
```

### 3.3 模块结构

```
src/
└── sort.js          # 排序算法实现
    └── quickSort()  # 主入口
```

### 3.4 测试计划

- 普通数组：`[3, 1, 4, 1, 5, 9, 2, 6]`
- 空数组：`[]`
- 单元素：`[42]`
- 已排序：`[1, 2, 3, 4, 5]`
- 逆序：`[5, 4, 3, 2, 1]`
- 含重复：`[2, 2, 2, 1, 1]`
- 自定义比较器降序

## 5. 风险与约束

- **风险**：最坏 O(n²) 在已排序逆序输入时触发，可通过随机化 pivot 缓解（后续优化）
- **约束**：不引入外部依赖，纯 ES6 实现
