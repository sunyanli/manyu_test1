# 需求澄清文档 — 组织架构与人员管理系统

> 生成日期：2026-07-15 | 阶段：clarify | 技能：brainstorming

---

## 一、项目上下文

| 维度 | 发现 |
|------|------|
| 仓库状态 | 新项目，无现有后端/前端代码 |
| 现有技术栈 | TypeScript + Node.js（来自 test-report-generation 工具，与本次需求无关） |
| 本次需求 | 全新全栈项目，从零搭建 |

## 二、关键技术决策

| 决策点 | 选择 | 依据 |
|--------|------|------|
| 后端框架 | Node.js + NestJS (TypeScript) | 与现有仓库 TypeScript 生态一致；企业级 DI/IoC 模式 |
| 前端框架 | Vue 3 + Element Plus | 需求文档提及，中文社区企业主流选择 |
| 数据库 | MySQL 8.0 | 企业级应用最广泛的关系型数据库 |
| ORM | TypeORM | NestJS 生态原生支持，装饰器风格与 NestJS 一致 |
| 认证方案 | JWT + RBAC | 三种角色（超管/HR/部门主管），需权限隔离 |
| API 风格 | RESTful | 需求文档已给出完整 API 协议 |

## 四、边界问题默认推断

| 问题 | 默认推断 | 理由 |
|------|---------|------|
| 部门主管权限范围 | 可查看本部门及所有子部门的人员，可编辑本部门直属人员的基础信息（非敏感字段） | 需求描述"仅可查看本部门及下属部门的人员，可编辑本部门人员部分信息" |
| 员工"部分信息"定义 | 职位、联系电话等非敏感字段；不可编辑工号、薪资等 | 最小权限原则 |
| 部门删除策略 | 仅当部门下无子部门且无员工时允许删除 | 需求已明确"有人员禁止删除"，扩展为包含子部门 |
| 员工数据物理删除 | 永不允许物理删除，仅逻辑删除 | 需求明确"严禁物理删除" |
| 多租户/公司隔离 | 单公司模式，暂不需要多租户 | 需求未提及多公司 |
| 拖拽跨级限制 | 允许任意层级拖拽，仅校验循环引用 | 需求未限制跨越层级 |

## 六、数据库核心设计

### departments 表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT PK | 主键 |
| parent_id | INT | 父部门ID，NULL 为根节点 |
| name | VARCHAR(100) | 部门名称 |
| path | VARCHAR(500) | 路径如 `1-2-5`，加速子树查询 |
| sort_order | INT | 排序 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

### employees 表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT PK | 主键 |
| name | VARCHAR(50) | 姓名 |
| employee_no | VARCHAR(50) UNIQUE | 工号，唯一索引 |
| phone | VARCHAR(20) UNIQUE | 手机号，唯一索引 |
| dept_id | INT INDEX | 所属部门 |
| position | VARCHAR(100) | 职位 |
| status | ENUM('active','resigned') | 在职/离职 |
| version | INT DEFAULT 0 | 乐观锁版本号 |
| resign_date | DATE | 离职日期 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

### transfer_logs 表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT PK | 主键 |
| employee_id | INT | 员工ID |
| from_dept_id | INT | 原部门 |
| to_dept_id | INT | 新部门 |
| from_position | VARCHAR(100) | 原职位 |
| to_position | VARCHAR(100) | 新职位 |
| reason | VARCHAR(500) | 调动原因 |
| operator_id | INT | 操作人 |
| created_at | DATETIME | 操作时间 |
