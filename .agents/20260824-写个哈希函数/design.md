## 1. 问题陈述

在 JS/TS 中实现一个**字符串哈希函数**，将字符串输入映射为固定长度的 32-bit 整数哈希值，用于**哈希表键 / 缓存键**场景。

### 已确认的需求

| 维度 | 决策 |
|------|------|
| 编程语言 | TypeScript |
| 用途场景 | 字符串哈希（哈希表 / 缓存键） |
| 核心要求 | 速度快、零依赖、分布均匀 |
| 非目标 | 密码学安全 / 文件校验 |

## 2. 方案对比

### 方案 A：简单字符串哈希（djb2 / FNV-1a）

| 项目 | 说明 |
|------|------|
| **算法** | djb2 或 FNV-1a，经典的非加密字符串哈希 |
| **输出** | 32-bit 整数 |
| **适用场景** | 哈希表键、路由分发、负载均衡 |
| **优点** | 实现极简（~10 行）、速度快、分布均匀 |
| **缺点** | 非加密安全、碰撞可构造 |
| **推荐度** | ⭐⭐⭐ 通用推荐 |

### 方案 B：非加密通用哈希（xxHash / SipHash）

| 项目 | 说明 |
|------|------|
| **算法** | xxHash (xxh3) 或 SipHash-1-3 |
| **输出** | 64-bit 或 128-bit |
| **适用场景** | 高性能哈希表、缓存键、校验和 |
| **优点** | 速度极快（xxHash 是现代最快非加密哈希）、分布均匀性优于 djb2 |
| **缺点** | 需依赖库（`xxhash-wasm` / `siphash`） |
| **推荐度** | ⭐⭐⭐ 生产环境推荐 |

### 方案 C：加密哈希（SHA-256 / SHA-3）

| 项目 | 说明 |
|------|------|
| **算法** | SHA-256 (SHA-2 家族) |
| **输出** | 256-bit (32 字节) hex 字符串 |
| **适用场景** | 密码/令牌存储、数字签名、数据完整性验证 |
| **优点** | 密码学安全（抗碰撞、单向性）、Web Crypto API 内置支持，零依赖 |
| **缺点** | 速度比非加密哈希慢 10-100 倍 |
| **推荐度** | ⭐⭐ 安全场景推荐 |

### 方案 D：自定义教学哈希（从零实现）

| 项目 | 说明 |
|------|------|
| **算法** | 自定义混合（如 Jenkins 一勺改 + 自定义 mixing） |
| **输出** | 32-bit 或 64-bit |
| **适用场景** | 学习/教学目的 |
| **优点** | 完全自控、适合理解哈希原理 |
| **缺点** | 分布均匀性未经验证、有碰撞/安全风险 |
| **推荐度** | ⭐ 仅限学习场景 |

## 3. 选定方案

**确认方案：方案 A — djb2 哈希**

原因：
- 零依赖，纯 TypeScript 实现，约 10 行核心代码
- 适用于哈希表/缓存键场景，分布均匀性足够
- 32-bit 输出，适合 JS 的 number 类型（按位运算安全到 32-bit）

### 算法说明

djb2 由 Daniel J. Bernstein 提出，核心公式：

```
hash = 5381
hash = hash * 33 + c  （对每个字符 c 迭代）
```

选用 **33** 作为乘数（经验值，分布效果好且移位+加法即可实现：`hash * 33 = (hash << 5) + hash`）。

### 备选：FNV-1a（若发现 djb2 碰撞率偏高）

FNV-1a 公式：
```
hash = 2166136261
hash = (hash ^ c) * 16777619  （对每个字符 c 迭代）
```

FNV-1a 在短字符串上分布略优于 djb2，但速度稍慢（乘法不可优化为移位）。

## 4. 接口设计（TypeScript）

```typescript
/**
 * 字符串哈希函数 — 哈希表 / 缓存键场景
 * 返回 32-bit 无符号整数
 */
function hashString(input: string): number;
```

```typescript
/**
 * 双哈希接口（用于开放寻址哈希表）
 * 返回两个不同的 32-bit 哈希值
 */
function hashStringPair(input: string): [number, number];
```

### 设计要点

| 要点 | 说明 |
|------|------|
| 输入类型 | `string`（字符串哈希专用） |
| 输出类型 | `number`（32-bit 无符号整数，JS 位运算安全） |
| 返回值 | 直接返回整数，无需 hex 转换 |
| 额外 | `hashStringPair` 提供双哈希，支持布隆过滤器或双哈希表 |

## 5. 性能预期

| 指标 | 预期 |
|------|------|
| 吞吐量 | ~50-100M 字符/秒（V8 引擎） |
| 碰撞率 | 约 1/2^32（与随机分布接近） |
| 代码体积 | < 0.5 KB |
